# Data origin

All applicant scores, potential outcomes, treatment statuses and Monte Carlo results are generated locally from the declared seeds and model. There are no real participants, downloaded empirical data, manually acquired inputs, private credentials or access restrictions. There are no empirical source URLs to retrieve.

The implementation uses NumPy, pandas, Matplotlib and ReportLab; pinned versions are in environment/requirements.txt. A fresh environment needs those software dependencies. After installation, the full replication can run offline. The statistical formulas and estimators are those documented in this package and the accompanying manuscript.
